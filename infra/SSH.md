# SSH(公開鍵認証での接続設定)

## 1. クライアント側で鍵ペアを作成する

接続元(クライアント)のマシンで、公開鍵と秘密鍵のペアを作成します。

```bash
ssh-keygen -t rsa -b 4096 -f id_rsa_py
```

| オプション | 内容 |
|---|---|
| `-t rsa` | 鍵の方式にRSAを指定 |
| `-b 4096` | 鍵長を4096ビットに指定(強度が高い) |
| `-f id_rsa_py` | 生成するファイル名(省略するとデフォルトの `id_rsa` になる) |

macOSの場合、`/var/root/.ssh/` に `id_rsa.pub`(公開鍵)と `id_rsa`(秘密鍵)が作成されます。

### パーミッションを調整する

SSHは秘密鍵のパーミッション(権限)が緩すぎると、セキュリティ上の理由で**鍵を無視する**仕様になっています。そのため、適切な権限に絞る必要があります。

```bash
chmod 700 /var/root/.ssh
chmod 700 /var/root/.ssh/
chmod 600 /var/root/.ssh/id_rsa
```

| パス | 権限 | 意味 |
|---|---|---|
| `.ssh` ディレクトリ | 700 | 所有者のみ読み書き実行可能 |
| `id_rsa`(秘密鍵) | 600 | 所有者のみ読み書き可能(他人は一切アクセス不可) |

## 2. 公開鍵をホストに転送する

接続先(ホスト)に公開鍵を登録します。`ssh-copy-id` を使うと、ホスト側の `~/.ssh/authorized_keys` に公開鍵が自動的に追記されます。

```bash
ssh-copy-id -i /var/root/.ssh/id_rsa.pub user@example.com
```

`-i` オプションで指定するのは、秘密鍵ではなく **`.pub` が付いた公開鍵のパス**である点に注意してください。

---

## 3. 秘密鍵を使ってSSH接続する

```bash
ssh -i /var/root/.ssh/id_rsa user@example.com
```

`-i` オプションで秘密鍵のパスを指定して接続します。

## 4. パスワード認証を無効化する(特定IPのみ許可)

公開鍵認証に一本化する前提で、パスワード認証を無効化します。ただし、社内ネットワークなど特定のIPレンジからは例外的にパスワード認証を許可する設定も併せて行います。

```bash
sudo nano /etc/ssh/sshd_config
```

ファイルの最終行に以下を追加します。

```
PasswordAuthentication no
Match Address 192.168.0.0/16
  PasswordAuthentication yes
```

- `PasswordAuthentication no`: 全体としてパスワード認証を禁止(公開鍵認証のみ許可)
- `Match Address 192.168.0.0/16` 以下: 指定したIPレンジ(この例では `192.168.0.0/16`)からの接続に限り、例外的にパスワード認証を許可

> **注意**: `Match` ブロックは設定ファイルの中で条件付き設定を行うためのもので、対象となる設定項目は必ずインデント(字下げ)して記述する必要があります。

### 設定ファイルの文法チェック

設定を反映する前に、構文エラーがないか確認します。

```bash
sudo sshd -t
```

何も出力されなければ問題ありません。エラーがある場合は反映後にSSH接続自体ができなくなるおそれがあるため、必ず反映前に確認してください。

### 設定を反映する

```bash
sudo systemctl restart ssh
```

## 5. ホスト側の公開鍵認証設定を確認する

多くのディストリビューションではデフォルトで有効になっていますが、公開鍵認証が効かない場合は以下の設定を確認してください。

```bash
sudo nano /etc/ssh/sshd_config
```

```
PubkeyAuthentication yes
AuthorizedKeysFile      .ssh/authorized_keys .ssh/authorized_keys2
```

- `PubkeyAuthentication yes`: 公開鍵認証を有効化
- `AuthorizedKeysFile`: 公開鍵を探すファイルのパス(複数指定可)

設定変更後は反映のためSSHサービスを再起動します。

```bash
sudo systemctl restart ssh
```

> **補足**: 多くの環境ではこの設定はデフォルトで有効になっているため、公開鍵認証が正常に動作している場合はこの手順は不要です。
