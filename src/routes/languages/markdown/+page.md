## 基本記法

### リスト

`-` や `*` で箇条書きを作成します。インデントすることで階層(ネスト)を表現できます。

```markdown
* リスト1
  * リスト2-1
```

### 番号付きリスト

数字と `.` で番号付きリストを作成します。番号は自動採番されるため、すべて `1.` と書いても連番で表示されます。

```markdown
1. 番号付き
   1. 番号付き
```

> **注意**: ネストする場合、子リストの前にスペースでのインデントが必要です(元の記法ではスペースが抜けていたため、正しく階層化されない場合があります)。

### 引用

`>` を使います。`>>` のように重ねることで、引用の中の引用(ネスト)を表現できます。

```markdown
> 引用1
>> 引用2
```

### コード記法(インラインコード)

バッククォート `` ` `` で囲むと、文中にインラインコードとして表示できます。

```markdown
`code`
```

### 強調表示

アスタリスク `*` の数で、斜体・太字を使い分けます。

```markdown
*italic*
**bold**
***italic+bold***
```

| 記法 | 表示 |
|---|---|
| `*italic*` | イタリック(斜体) |
| `**bold**` | 太字 |
| `***italic+bold***` | 斜体+太字 |

### 水平線

ハイフンを3つ以上並べると、区切り線が引かれます。

```markdown
---
```

### リンク

**通常のリンク記法**

```markdown
[Google](https://www.google.co.jp/)
```

`[表示テキスト](URL)` の形式で記述します。

**参照方式のリンク**

文中で使うリンクの実体を、文書の別の場所でまとめて定義する書き方です。同じURLを何度も使う場合や、文中を読みやすく保ちたい場合に便利です。

```markdown
[参照方式のリンク][google]

[google]: https://www.google.co.jp/
```

`[表示テキスト][識別子]` として本文中に置き、`[識別子]: URL` の形式でリンク先を別の行(通常は文末など)にまとめて定義します。

## GitHub Flavored Markdown(GFM)

GitHub上でのみ使える(または特に便利な)拡張記法です。

### オートリンク

URLをそのまま記述するだけで、自動的にリンクとして認識されます。

```markdown
https://www.google.co.jp/
```

### コードブロック(言語指定つき)

3つのバッククォートで囲むことで、複数行にわたるコードブロックを作成できます。バッククォートの直後に言語名を書くと、シンタックスハイライト(色分け表示)が適用されます。

<pre>
```ruby
class Hoge
end
```
</pre>

> **補足**: コードブロックの中でさらにバッククォート3つを使う例を示したい場合(このドキュメントのように)、外側を4つのバッククォートで囲むと、内側の3つがそのまま表示されます。

### 表組み

`|` で列を区切り、2行目でセルの配置(左詰め・中央・右詰め)を指定します。

```markdown
|左詰|中央|右詰|
|:--|:--:|--:|
|左|中|右|
```

| 記法 | 内容 |
|---|---|
| `:--` | 左詰め |
| `:--:` | 中央揃え |
| `--:` | 右詰め |
