# MariaDB

MariaDBはMySQL互換のオープンソースデータベースサーバーです。このドキュメントでは、インストールから初期設定、管理ユーザーの作成までの手順をまとめます。

## インストール手順

パッケージリストを更新してから、MariaDBサーバーをインストールします。

```bash
sudo apt update
sudo apt install mariadb-server
```

---

## セキュリティ初期設定

インストール直後は最低限のセキュリティ設定しかされていないため、専用のセットアップスクリプトを実行して初期設定を行います。

```bash
sudo mysql_secure_installation
```

このコマンドを実行すると、対話形式で以下のような項目を聞かれます。

- rootパスワードの設定
- 匿名ユーザーの削除
- rootの外部(リモート)ログインを禁止するか
- テスト用データベースの削除
- 権限テーブルの再読み込み

基本的にはすべて `Y`(はい)で進めて問題ありません。

## 管理ユーザーの作成

MariaDBのシェルに入り、管理用ユーザーを作成します。

```bash
sudo mariadb
```

MariaDBのプロンプト(`MariaDB [(none)]>`)に入ったら、以下を実行します。

```sql
GRANT ALL ON *.* TO 'admin'@'localhost' IDENTIFIED BY 'password' WITH GRANT OPTION;
```

| 項目 | 内容 |
|---|---|
| `'admin'` | 作成するユーザー名 |
| `'localhost'` | このユーザーがログインを許可される接続元(ローカルからのみ) |
| `IDENTIFIED BY 'password'` | ユーザーのパスワード(実運用では推測されにくいものに変更する) |
| `ALL ON *.*` | 全データベース・全テーブルに対する全権限を付与 |
| `WITH GRANT OPTION` | このユーザーが他のユーザーに権限を付与できるようにする |

> **注意**: `'password'` の部分は必ず実際の強固なパスワードに置き換えてください。このまま使うとセキュリティリスクになります。

## 動作確認

MariaDBが正しく動作しているか、バージョン情報を取得して確認します。

```bash
sudo mysqladmin version
```

バージョン番号や稼働時間(Uptime)などが表示されれば、正常にインストール・起動できています。
